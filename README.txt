Publishing on xneelo:
1. Add a Web Hosting package to your domain.
2. In the xneelo Control Panel, open File Manager for the domain.
3. Upload the contents of this folder to the public web root.
4. Ensure index.html sits in the web root.
5. Enable/confirm SSL and force HTTPS.
6. Replace placeholder phone details when confirmed.

The site is static and does not require a database.
